# exhibitViewer
a lightweight python pdf viewer with ability to place exhibit stickers designed for use in legal contexts.

features:
- view multiple pdf's in different tabs
- zoom in, zoom out
- browse between pages
- place yellow exhibit stickers with top and bottom text
- undo and redo
- save pdf with stickers

known issues:
- undo and redo is unstable
- placing stickers in specific locations can be unreliable
